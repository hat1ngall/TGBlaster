Telegram Mass Sender Bot

Надёжный скрипт для автоматической рассылки сообщений со ссылками по списку Telegram-чатов. Реализован на Pyrogram (Userbot), поддерживает форматирование, антиспам-задержки, автовступление в чаты и подробное логирование.

Ключевые возможности

Userbot (Pyrogram)

Работает от имени реального аккаунта. Может писать в любые чаты без добавления бота.

Автовступление

Автоматически вступает в открытые группы и каналы перед отправкой, если аккаунта там нет.

Anti-FloodWait

Случайные задержки от 30 до 120 секунд между отправками. Обработка FloodWaitError.

Сессионная авторизация

Авторизация по номеру телефона. Сессия сохраняется — повторный вход не требуется.

Гибкий формат

Поддержка Markdown и HTML форматирования. Превью ссылок включается/выключается.

Полное логирование

Вывод статуса каждой отправки в консоль и запись в лог-файл. Итоговая статистика.

⚠️ Важное предупреждение

Использование userbot'ов для массовой рассылки нарушает Terms of Service Telegram. Аккаунт может быть заблокирован. Используйте скрипт только в образовательных целях или для рассылки в чаты, которые вы администрируете. Скрипт реализует защитные меры (задержки, обработка ошибок), но не даёт 100% гарантии защиты.

tgblaster.py — Основной скрипт

Полный код скрипта с подробными комментариями. Сохраните файл как tgblaster.py в папку проекта.

Скрипт использует библиотеку Pyrogram (Userbot). При первом запуске потребуется ввести номер телефона и код подтверждения. Сессия сохраняется в файл tgblaster_session.session — повторный ввод не потребуется.

Важно: Перед запуском убедитесь что создали и заполнили config.json и chats.json. Шаблоны смотрите во вкладках «Конфигурация» и «Список чатов».

        Частые проблемы и решения
      

      
⚠ Pyrogram не установлен / ModuleNotFoundError
→ Выполните: pip install pyrogram tgcrypto

      
⚠ FloodWait: X seconds
→ Telegram просит подождать X секунд. Скрипт обрабатывает это автоматически. Увеличьте delay_min/delay_max в config.json

      
⚠ ChatWriteForbidden
→ Нет прав писать в чат. Чат может быть закрыт для неучастников или аккаунт замьючен.

      
⚠ UserDeactivatedBan
→ Аккаунт заблокирован Telegram. Слишком агрессивные рассылки. Используйте другой аккаунт.

      
⚠ Сессионный файл повреждён
→ Удалите файл tgblaster_session.session и запустите заново (потребуется повторная авторизация).

    


    

      

        
        Рекомендации по безопасности
      

      
Никогда не публикуйте config.json с реальными API ключами в публичные репозитории

      
Добавьте config.json и *.session в .gitignore если используете Git

      
Используйте отдельный Telegram аккаунт для рассылки, не основной

      
Не снижайте delay_min ниже 15-20 секунд — риск FloodWait и блокировки

      
Периодически проверяйте лог-файл на наличие повторяющихся ошибок

      
Не запускайте несколько экземпляров скрипта одновременно с одного аккаунта
